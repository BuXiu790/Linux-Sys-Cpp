# 📝 静态库 vs 动态库 极简笔记

## 💡 一句话核心概念
* **静态库 (`.a` / `.lib`)**：链接时**打包复制**进可执行文件，程序独立性强，但体积较大。
* **动态库 (`.so` / `.dll`)**：链接时只记录**符号引用**，运行时按需加载，节省内存且易于更新。

---

## 🛠️ 最常用命令与示例 (以 GCC/Linux 为例)

### 1. 静态库的创建与使用
```bash
# 1. 编译生成目标文件 (.o)
gcc -c math_lib.c -o math_lib.o

# 2. 将 .o 文件打包为静态库 (必须以 lib 开头，.a 结尾)
ar rcs libmath.a math_lib.o

# 3. 编译主程序并链接静态库 (-L 指定库路径，-l 指定库名去掉 lib 和 .a)
gcc main.c -L. -lmath -o main_static

#动态库
# 1. 编译生成位置无关代码 (PIC) 的目标文件
gcc -fPIC -c math_lib.c -o math_lib.o

# 2. 打包生成动态共享库
gcc -shared math_lib.o -o libmath.so

# 3. 编译主程序并链接动态库
gcc main.c -L. -lmath -o main_dynamic

# 4. 运行主程序 (临时指定动态库寻找路径)
LD_LIBRARY_PATH=. ./main_dynamic
