# Linux 文件查找与文本处理：`find`、`grep`、`sort`、`wc`

## 1. 工具概览

| 命令 | 核心功能 | 典型场景 |
| --- | --- | --- |
| `find` 🔍 | 查找文件或目录 | 按名称、类型、大小等条件在指定路径中寻找文件 |
| `grep` 🔎 | 检索并过滤文本内容 | 在文件或命令输出中找出匹配的行 |
| `sort` 🗂️ | 对文本行排序 | 按字母或数值排序，也可以去除重复行 |
| `wc` 🔢 | 统计文本数量 | 统计行数、单词数或字节数 |

---

## 2. 命令详解与常用参数

### 2.1 `find` —— 文件搜索

#### 基本语法

```bash
find [路径] [匹配条件]
```

#### 常用参数

| 参数 | 作用 |
| --- | --- |
| `-name "文件名"` | 按文件名匹配，支持 `*` 等通配符 |
| `-type f` | 只查找普通文件 |
| `-type d` | 只查找目录 |
| `-size +10M` | 查找大于 10 MiB 的文件 |
| `-size -10M` | 查找小于 10 MiB 的文件 |

> 使用 `*` 等通配符时，通常要用引号包住匹配表达式，避免 Shell 提前展开它。

#### 示例

查找 `/var/log` 目录及其子目录中的所有 `.log` 文件：

```bash
find /var/log -type f -name "*.log"
```

---

### 2.2 `grep` —— 内容检索

#### 基本语法

```bash
grep [选项] "查找内容" 文件
```

#### 常用参数

| 参数 | 作用 |
| --- | --- |
| `-n` | 显示匹配行的行号 |
| `-i` | 忽略英文字母大小写 |
| `-v` | 反向选择，只输出不匹配的行 |
| `-r` | 递归查找目录下的文件 |

#### 示例

在 `server.log` 中忽略大小写查找 `error`，并显示行号：

```bash
grep -ni "error" server.log
```

---

### 2.3 `sort` —— 文本排序

#### 基本语法

```bash
sort [选项] 文件
```

#### 常用参数

| 参数 | 作用 |
| --- | --- |
| `-n` | 按数值大小排序，而不是按字符顺序排序 |
| `-r` | 反向排序，即降序排列 |
| `-u` | 排序并去除重复行 |

#### 示例

将 `prices.txt` 中的数字按从大到小排列：

```bash
sort -nr prices.txt
```

---

### 2.4 `wc` —— 文本统计

#### 基本语法

```bash
wc [选项] 文件
```

#### 常用参数

| 参数 | 作用 |
| --- | --- |
| `-l` | 统计行数（Line，最常用） |
| `-w` | 统计单词数（Word） |
| `-c` | 统计字节数（Byte） |

#### 示例

统计 `users.txt` 的总行数：

```bash
wc -l users.txt
```

## 3. 管道符 `|` 与 `xargs`

### 3.1 管道符 `|`

管道符会把前一个命令的标准输出，作为后一个命令的标准输入。这样可以把多个简单命令连接成一条处理流水线。

```text
命令 1 的输出 → 命令 2 的输入 → 命令 3 的输入
```

### 3.2 `xargs`

`xargs` 会把从标准输入读到的内容转换成后续命令的参数。它常用于把 `find` 找到的一批文件交给另一个命令处理。

基本形式：

```bash
前一个命令 | xargs 后一个命令
```

## 4. 实战组合

### 统计所有日志文件中包含 `ERROR` 的行数

目标：统计 `/var/log` 目录下所有 `.log` 文件中，包含 `ERROR` 的总行数。

更稳妥的写法：

```bash
find /var/log -type f -name "*.log" -print0 \
  | xargs -0 grep -h "ERROR" \
  | wc -l
```

处理流程：

1. `find` 找出所有 `.log` 普通文件。
2. `-print0` 使用空字符分隔文件名。
3. `xargs -0` 按空字符读取文件名，即使文件名中含空格也能正确处理。
4. `grep -h "ERROR"` 输出匹配行，并隐藏文件名。
5. `wc -l` 统计匹配行的总数。

也可以不用 `xargs`，直接使用 `find -exec`：

```bash
find /var/log -type f -name "*.log" \
  -exec grep -h "ERROR" {} + \
  | wc -l
```

> 注意：这里统计的是“包含 `ERROR` 的行数”。如果同一行中出现多个 `ERROR`，这一行仍然只计为 1 行。
