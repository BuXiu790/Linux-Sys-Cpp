# 📂 Linux 环境变量与 PATH 学习笔记

## 1. 环境变量（Environment Variables）

- **概念** 🌐：系统中的动态键值对，用来存储系统配置和运行环境信息。
- **常用操作** 🛠️：
  - 查看当前 `PATH`：`echo $PATH`
  - 临时设置或修改：`export 变量名=变量值`

---

## 2. PATH 变量与查找机制

- **作用** 🗺️：记录系统在执行命令时查找可执行文件的目录列表。
- **分隔符** 🔗：各个目录之间使用英文冒号 `:` 分隔，例如：`/usr/bin:/bin`。

### 🔍 PATH 的访问与查找顺序（核心逻辑）

- 系统寻找命令时，会按 `PATH` 中的目录**从左到右依次查找**。
- **匹配即止**：只要在靠前的目录里找到了对应的程序，系统就会**立即停止寻找并直接执行**它，不再继续查看后面的目录。
- **优先级与追加方式**：
  - **后置追加（默认推荐）**：`export PATH=$PATH:/你的路径`
    - 优先使用系统自带命令，自定义命令作为补充。
  - **前置追加（优先覆盖）**：`export PATH=/你的路径:$PATH`
    - 优先使用你的自定义程序，可用于覆盖系统同名命令。

---

## 3. 永久生效配置

- **临时生效** ⏳：直接在终端中使用 `export` 命令，仅对当前终端及其启动的子进程有效。
- **永久生效** 🏠：将 `export` 命令写入家目录下的用户配置文件，例如 `~/.bashrc`。
- **生效机制** 🔄：启动新的交互式 Bash 终端时，系统通常会读取并执行 `~/.bashrc` 中的命令。

修改 `~/.bashrc` 后，可以执行下面的命令，让配置立即在当前终端生效：

```bash
source ~/.bashrc
```
